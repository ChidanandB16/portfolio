Campus-Connect

One platform for courses, materials and enrollments.

Access is role-based, with JWT authentication and bcrypt password hashing. The frontend is built in TypeScript, and the project is wired with Git, Maven and Jenkins build workflows.

Wanderlust

An Airbnb-style app for finding and sharing stays.

Users browse listings with photos, prices and locations, sign up and log in, create their own listings with image uploads, and leave ratings and reviews. Owners can edit or delete only their own listings.

Each listing is placed on a map, with the location geocoded when it's created. It's live on Render, so you can click around it.

03

Real-Time Object Surveillance

Spotting abandoned bags by tracking who they belong to.

A computer vision system that detects unattended baggage in video. YOLOv8s finds people and bags, ByteTrack follows them across frames, and OSNet re-identification links a bag to its owner.

Instead of using only distance and time, it uses the owner's identity and a dynamic risk score, which helps in crowded scenes. It runs on CPU and has a live Streamlit dashboard.
